# accordion — 手风琴纸牌接龙

终端里的 Accordion Solitaire。纯标准库, 零依赖。

## 玩法

52 张牌依次发成一排。从左往右, 每一张牌可以放到左边**第 1 张或第 3 张**位置上的牌堆顶,
条件是两张牌**花色相同或点数相同**。被覆盖的牌堆叠在一起。目标: 最终只剩 **1 个牌堆**即获胜。

```bash
python -m accordion            # 交互游玩
python -m accordion --seed 42  # 指定随机种子
python -m accordion --auto     # 机器人自动游玩 (优先 3-left 跳跃)
```

命令: `<i> <j>` 把牌堆 i 放到牌堆 j 上 (例如 `4 1`), `q` 退出。

## 设计取舍

- 机器人优先 3-left 跳跃: 经验上 3-left 更容易消掉中间牌堆, 实测胜率略高于只走 1-left。
- 发牌顺序即洗牌结果, 牌序固定后交互和 `--auto` 走的是同一局。
- 行输入模式 (每步回车), 无单键操作。

## 已知局限

- 手风琴接龙本身极难获胜: 本项目的贪心机器人实测 500 局 0 胜, 只是"演示走子", 不是解题器。
- 无悔棋、无存档、无最佳成绩。
- 交互模式需要终端 (tty); 管道/脚本场景请用 `--auto`。
